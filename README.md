# 🎄 Christmas Love Heart Animation ❤️

A small creative web project built with **HTML, CSS, and JavaScript**.  
This animation displays a romantic text moving smoothly along a heart-shaped path, combined with a Christmas snow effect and a simple festive greeting.

The project focuses on animation logic, canvas rendering, and responsive layout for both desktop and mobile screens.

---

## ✨ Features

- ❤️ Heart-shaped text animation
- 🔁 Smooth continuous motion
- ❄️ Snow falling effect using Canvas
- 🎄 Simple Christmas greeting
- 📱 Responsive layout (Desktop & Mobile)
- ⚡ Lightweight, no external libraries
